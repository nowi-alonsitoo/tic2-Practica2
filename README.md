README – TIC II · PRÁCTICA 03
Portfolio personal – Noé Gayoso Alonso
1. DESCRIPCIÓN DEL PROYECTO

Este proyecto consiste en la creación de una página web personal a modo de portfolio, desarrollada para la asignatura de TIC II de 2.º de Bachillerato del colegio Salesianos A Coruña.

La página tiene como objetivo presentar información personal y académica, mostrar mis intereses y recopilar algunos de los trabajos y prácticas realizados durante el curso.

El portfolio está diseñado como una página de presentación sencilla, visual y organizada, utilizando HTML, CSS y Bootstrap.

2. ESTRUCTURA DEL PROYECTO

El proyecto está organizado en diferentes archivos y carpetas para facilitar su mantenimiento y funcionamiento.

index.html: página principal de bienvenida al portfolio.
pagina1.html: página donde se encuentra la presentación personal y el apartado de proyectos.
css/styles.css: hoja de estilos externa con el diseño personalizado de la página.
img2/: carpeta que contiene las imágenes, el avatar, los fondos de vídeo y otros recursos gráficos.
Ejercicio1/: carpeta que contiene el primer ejercicio realizado, formado por varias páginas HTML.
tic2-practica1/: carpeta que contiene la primera práctica de TIC II relacionada con la elección de futuros trabajos y carreras universitarias.
3. CONTENIDO DE LA PÁGINA WEB

La página principal funciona como portada del portfolio. Contiene un título de bienvenida, un fondo de vídeo animado y un menú de navegación que permite acceder a los diferentes apartados.

En la segunda página se encuentran los siguientes apartados:

¿Quién soy?

Incluye una presentación personal con mi nombre, centro educativo, curso académico, intereses y objetivos de futuro. También incorpora un avatar personalizado y un correo electrónico de contacto.

Proyectos

Contiene un índice visual de los trabajos realizados durante la asignatura de TIC II. Cada proyecto aparece representado mediante una tarjeta con una imagen, un título, una breve descripción y un enlace para acceder directamente a él.

Presentación del portfolio

Incluye un pequeño texto introductorio que explica la finalidad de la página y los conocimientos adquiridos durante el desarrollo de las diferentes prácticas.

4. TECNOLOGÍAS UTILIZADAS

Para desarrollar este proyecto se han utilizado las siguientes tecnologías:

HTML5: para crear la estructura y el contenido de las páginas.
CSS3: para personalizar el diseño, los colores, los fondos, las tarjetas y los elementos visuales.
Bootstrap 5.3.8: para facilitar el diseño y la distribución de los elementos, utilizando componentes como tarjetas, botones, contenedores y sistemas de navegación.
JavaScript de Bootstrap: mediante el archivo bundle para disponer de las funcionalidades de Bootstrap.
5. DISEÑO Y FUNCIONALIDADES

El diseño del portfolio busca ofrecer una apariencia moderna y atractiva.

Entre sus características principales destacan:

Fondos de vídeo animados y reproducidos automáticamente.
Diseño adaptable a diferentes tamaños de pantalla mediante Bootstrap.
Menú de navegación para desplazarse entre las páginas y sus apartados.
Tarjetas visuales para presentar los diferentes proyectos.
Avatar personalizado en la presentación personal.
Estilos propios mediante una hoja CSS externa.
Enlaces internos y relativos para acceder a los distintos archivos del proyecto.
6. FUENTES Y ATRIBUCIONES

Los recursos utilizados en el proyecto son los siguientes:

Bootstrap: framework CSS y JavaScript obtenido de https://getbootstrap.com/
Avatar personal: imagen utilizada en el apartado «¿Quién soy?», guardada en img2/AvatarMaker.png.
Imágenes y vídeos: recursos gráficos y audiovisuales en la carpeta img2/.
